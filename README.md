# 📝 Vanilla Notes App

A simple Notes App built with **HTML**, **CSS**, and **Vanilla JavaScript**.  
It allows users to:

- Add notes
- Edit notes directly
- Delete notes
- Store notes persistently using **Local Storage**

---

## 🌟 Features

- 🚫 No frameworks or libraries — just plain JavaScript!
- 💾 Notes are saved in the browser using `localStorage`
- 🖊️ Edit notes inline (no popups or alerts)
- ❌ Delete any note easily
- 🎨 Styled with CSS for a clean and modern look

---
## 💡 How It Works

- Notes are stored as objects in an array and saved to `localStorage`
- `localStorage` keeps your notes even after refreshing or closing the tab
- You can type in a text input to add a note
- Each note has **Edit** and **Delete** buttons
- Editing allows inline changes
